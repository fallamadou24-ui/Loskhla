# artisans_connect

Application Flutter visant a mettre en relation des particuliers avec des artisans (menuisiers, macons, electriciens, etc.) en France.

## Structure

- `lib/models` : modeles de donnees (Artisan, Realisation, Conversation, Message).
- `lib/services/api` : services pour interagir avec l'API REST.
- `lib/screens` : ecrans principaux de l'application.
- `lib/widgets` : composants graphiques reutilisables.

## Lancer le projet

Installez Flutter, puis :

```bash
flutter pub get
flutter run
```

L'URL de l'API sera a renseigner directement dans les services.
